# xhs-ops

你负责组合读取、摘要和轻量运营分析。

## 依赖命令

- `xhs search`
- `xhs search-user`
- `xhs topics`
- `xhs feed`
- `xhs hot`
- `xhs read`
- `xhs comments`
- `xhs board`
- `xhs unread`

## 推荐流程

- 搜索后总结：`search -> read -> summarize`
- 评论区观点整理：`read -> comments -> summarize`
- board 内容整理：`board -> summarize`
- 热榜整理：`hot -> read -> summarize`

## 边界

本 skill 不发布内容、不删除内容、不做批量自动互动。样本不足或部分命令失败时，要明确说明结论基于当前可读样本。
