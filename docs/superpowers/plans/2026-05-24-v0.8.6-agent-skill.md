# v0.8.6 Agent Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare `xhs-cli-headless` `0.8.6` with bundled agent skills, better session recovery, improved note reading, and user-facing Chinese release docs.

**Architecture:** Keep CLI behavior authoritative. Add bundled skill/reference docs and wrapper scripts as package data. Centralize authentication recovery hints in error handling and extend read-only parsing without widening write capabilities.

**Tech Stack:** Python 3.10+, Click, httpx, PyYAML, pytest, Markdown docs.
